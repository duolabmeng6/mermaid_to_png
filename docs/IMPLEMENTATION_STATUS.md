# PNG 出图体验改进记录

目标：在 Mermaid 原生渲染边界内，让排版、编辑、保存和导出形成完整流程。本轮以原生排版、可靠文档和实际 PNG 出图为交付范围；以下列出验收证据及兼容性边界。

## 已实现

- 排版：文字宽度、留白、字号、流程图节点/层级间距；内置方案与自定义配置导入导出；排版撤销重做。
- 导出：实际 PNG 检查、原始像素查看、复制图片、下载同一张 PNG、尺寸限制提示、批量导出。
- 文档：源码和完整出图设置一起保存；新建、命名、切换、副本、导入导出；上次有效备份恢复；回收站；多标签页冲突提示及未保存时离开保护。
- 流程图表达：单节点与批量配色、字体、边框；使用 Mermaid 原生 style 语句，保留手写样式，支持撤销。
- 脑图布局：同级分支拖动、上移下移、跨父级移动；折叠、逐个展开与全部展开；隐藏内容保存在源码注释中。
- 查找和性能：当前展开节点搜索；大纲导航与画布选择联动；脑图层级索引使用迭代遍历；主预览优先调度与过期排队任务取消。
- 补充资料与连续编辑：节点备注和安全资料链接；输入法组词保护；撤销保持编辑区域；触屏可用的节点操作入口。

## 验证范围

- 单元测试：配置与文档序列化、非法数据拒绝、保存失败、备份保留、原生样式生成、分支排序与折叠还原。
- Vue 生命周期集成测试：文档自动保存、未落盘编辑时切换文档、多标签页冲突、删除恢复和回收站。
- Mermaid 实际解析器：生成的流程图 style 语句通过完整预处理和解析，节点样式进入 Mermaid 数据模型。测试仅替换解析所需的 DOM 文本净化依赖，不覆盖真实浏览器渲染或安全性。
- 构建和 TypeScript 检查。

- 实际双击脑图节点改字、Tab 新建子节点、折叠及展开全部，大纲随之更新，源码正确保留隐藏内容。
- 排版方案与撤销生效；长中文流程图节点调宽后从两行变为单行；节点字号 20px 和配色进入 SVG 与实际 PNG。
- PNG 复制按钮成功后，通过真实粘贴事件读取到 image/png（47,781 字节），不是只模拟 Clipboard API。
- 文档刷新恢复、移入回收站和恢复通过，源码与排版设置保留；备注链接保存进入源码。
- 全屏导出图片正常；Escape 关闭弹窗可用。浏览器原生全屏状态下 Escape 可能先退出全屏。
- 390px 宽视口无页面横向溢出，大纲可用；图像超出画布时仍可滚动。

发现并修复：

1. Mermaid 11.17 的脑图居中形状 SVG 文字缺少 text-anchor，中心文字向右偏移。通过 Mermaid themeCSS 补充仅适用于居中标签的锚点，让主预览、缩略图和导出共用修正。
2. 手机宽度下出图下拉框被 flex 压缩到无法显示文字。增加 110px 最小宽度与换行基础宽度，复测各设置值正常显示。
