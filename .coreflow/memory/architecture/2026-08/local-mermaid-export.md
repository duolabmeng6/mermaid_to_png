# 本地 Mermaid 渲染与图片导出

- 规则：项目定位为个人本地工具，使用 Vue 3、TypeScript、Vite 和 Mermaid 在浏览器内完成解析、预览与导出；没有明确新增需求时不引入后端、数据库或远程渲染服务。
- 规则：核心界面保持中文工作区；单图时为左侧源码、右侧大图预览的双栏结构，多图时在两者之间增加缩略图栏；窄屏切换为上下布局。
- 规则：页面顶部应用标题栏与右侧图片预览标题栏使用约 48px 的单行紧凑布局，隐藏低价值副标题，以直接增加预览画布高度；左侧 Mermaid 编辑器标题栏进一步压缩至约 42px。不能保留 68px 的双行大标题栏。
- 规则：左侧 Mermaid 编辑器提供可键盘操作、带完整无障碍状态的收起/展开按钮；桌面端必须向左横向收起为约 50px 的窄栏，并让右侧预览占用释放出的宽度，不能只减少编辑器高度。小屏单列布局才降级为纵向收起。折叠编辑内容必须保留 textarea DOM、代码、选区、滚动位置和撤销历史。
- 规则：右侧预览必须支持整个面板全屏，且全屏中继续保留主题、背景、缩放、PNG/SVG 导出和大图滚动能力；优先使用浏览器原生 Fullscreen API，不可用或被嵌入环境拒绝时自动降级为铺满窗口的沉浸模式，并支持按钮和 `Esc` 退出。全屏中的导出结果提示必须保持可见；设置工具栏固定为 44px 高的单行布局，空间不足时横向滚动访问全部设置，不能换行挤占画布高度或直接裁切操作项。
- 规则：复杂大图预览不能只强制缩放到一屏；必须提供清晰可见的双向滚动条、适应窗口与明确缩放比例，并在重新渲染或切换缩放后把视图重置到可见内容位置。
- 规则：预览画布支持触控板式浏览：普通双指滑动使用原生双轴滚动，捏合手势围绕触点连续缩放并显示当前比例，鼠标主键可拖拽平移；同时保留滚动条、方向键、翻页键及缩放下拉框作为等价操作。不能拦截普通 wheel，也不能用 `transform: scale()` 破坏滚动范围。
- 规则：右侧设置栏提供流程图排版切换，横版使用 Mermaid `LR` 方向，竖版使用 `TD` 方向；切换只改变渲染输入，不改写左侧 Markdown/Mermaid 原文，并统一作用于大图预览、缩略图、PNG/SVG 和全部 ZIP 导出。
- 规则：编辑器验收必须包含真实点击聚焦、逐字输入、删除、撤销和 Tab 缩进；程序化整段 `fill()` 只能验证数据绑定，不能证明用户实际可编辑。
- 规则：编辑器使用 Vue 原生 `v-model` 的输入法组合事件保护；撤销/重做由编辑器维护有界历史（同时限制条数与字符总量），并恢复光标、选区与滚动位置，避免父组件回写破坏原生历史或长文本无限占用内存。
- 规则：SVG 直接以矢量文件导出；PNG 复用 Mermaid 官方 Live Editor 的 SVG → Image → Canvas 路线，提供 1–4 倍清晰度、最终像素提示、背景选择和 Canvas 尺寸保护。
- 规则：图表主题使用集中式预设配置；提供 Mermaid 11.17.2 支持的 11 个官方主题和 4 个基于官方 `base` 主题变量机制的精选主题。主题选择需按经典、现代、多彩、精选分组，显示当前三色预览，并与本地设置持久化、预览画布和 PNG/SVG 导出背景保持一致。
- 规则：深色主题选择纯白或透明背景时必须提示可读性风险；`themeVariables.background` 只参与 Mermaid 配色推导，实际导出背景仍由 SVG 背景矩形或 PNG Canvas 填充负责。
- 规则：Mermaid 使用严格安全模式；渲染需要防抖、串行队列和 revision 校验，语法错误时保留上一次成功预览但禁用导出。
- 规则：编辑区同时兼容纯 Mermaid 源码和包含多个 fenced `mermaid` 代码块的 Markdown；不能把整篇 Markdown 直接交给 Mermaid 解析。只有识别到多张图时，才在编辑器与大图预览之间显示真实渲染的可选缩略图栏；缩略图存在 Markdown 标题时显示标题，不存在时不补可见标题。单图时隐藏缩略图栏。右侧设置栏不得再显示上一张、下拉选择和下一张控件。
- 规则：实时预览与批量导出必须共用模块级 Mermaid 串行渲染队列，避免全局 Mermaid 实例的 initialize、parse、render 在不同任务之间互相覆盖。
- 规则：Mermaid 11.17 必须通过顶层 `htmlLabels: false` 生成纯 SVG 文本；已弃用的 `flowchart.htmlLabels` 会被顶层默认值遮蔽。导出前还需将 HTML 风格的 `<br>`、`<img>` 和常见空白实体转换为 XML 安全格式，避免尺寸解析失败或 `foreignObject` 污染 Canvas。
- 规则：草稿与设置只保存在当前浏览器；存储不可用时必须明确提示，不能声称已经保存。
- 规则：多图批量导出使用浏览器本地生成 PNG 后打包 ZIP；单张失败不阻断其他图片，ZIP 内写入失败清单。首版一次最多 50 张且累计 PNG 最多 200 MB，超限时提示降低清晰度或分批导出；ZIP 使用轻量 `fflate`，不自实现归档格式。
- 规则：线上版本使用 GitHub Pages 托管，`main` 分支推送后由 `.github/workflows/deploy-pages.yml` 自动执行 pnpm 安装、测试、生产构建和部署；生产资源基路径固定为 `/mermaid_to_png/`，本地开发仍使用 `/`。
- 规则：项目统一使用 `pnpm@11.11.0` 和 `pnpm-lock.yaml`；`node_modules`、`dist`、`.DS_Store` 与 `package-lock.json` 不进入仓库。
- 规则：公开入口为 `https://duolabmeng6.github.io/mermaid_to_png/`；该 GitHub 账号配置了 Pages 自定义域名，因此标准入口会跳转到 `https://my.rongyiapi.com/mermaid_to_png/`，不要为本项目擅自移除账号级自定义域名。
- 规则：仓库 README 顶部必须直接展示可点击的自定义域名使用地址，并在 `docs/images/` 保存一张可点击的桌面双栏主界面截图，方便 GitHub 访客无需安装即可理解和进入工具。
- 规则：线上页面顶部操作区必须提供可点击的 GitHub 仓库入口 `https://github.com/duolabmeng6/mermaid_to_png`；桌面端显示图标和文字，窄屏保留带无障碍名称的紧凑图标按钮。
- 规则：验收报告必须明确区分静态验证与浏览器端到端验证；只有实际完成代码粘贴、预览生成、错误恢复和 PNG/SVG 下载文件检查，才能声称核心功能已经完整测试。
